# EdumentX — Project Requirements
#
# This file lists every package the application needs at runtime
# and at build time. It is a documentation aid for teammates who
# want a single overview of the dependency surface — it is NOT a
# substitute for `package.json`, which is the authoritative
# source of truth for versions and is what `npm install` actually
# reads.
#
# Run `npm install` to install all of these. The lockfile
# (`package-lock.json`) pins transitive versions.
#
# Node.js >= 20.19.4 is required (see `package.json#engines`).
#
# Categorised by what the package does in the app. Versions match
# `package.json` as of the date of the last review (2026-07-16).
# If something is missing or out of date, update BOTH this file
# and `package.json`.

# ── Motion & interactivity layer (July 2026) ──────────────────
# The micro-interactions pass added a shared motion toolkit
# (lib/motion.ts + components/motion/*) on top of the
# already-installed Reanimated / worklets / gesture-handler
# stack. NO new dependencies were added — every hook and
# primitive in components/motion/* re-exports functionality
# from the three packages above.
#
#   lib/motion.ts                     — duration / easing / spring / scale tokens
#   components/motion/hooks.ts        — usePressScale, useSwitchThumb,
#                                       useActiveIndicator, useShake
#   components/motion/AnimatedPressable.tsx
#                                     — Animated.createAnimatedComponent(Pressable)
#   components/motion/ActivePill.tsx  — sliding segmented-control indicator
#   components/motion/SwitchThumb.tsx — animated switch thumb
#   components/motion/FieldShell.tsx  — form-field wrapper (focus / error / valid)
#   components/motion/Skeleton.tsx    — Skeleton / SkeletonRow / SkeletonText
#   components/motion/FloatingEmptyIcon.tsx
#                                     — gently floating empty-state icon
#   components/motion/index.ts        — barrel export
#
# Full design spec, hooks reference, and pattern catalogue:
#   Documentation/02-Design-System/motion.md
#
# Haptics (`expo-haptics`) are intentionally NOT installed yet —
# the follow-up that adds them requires a native rebuild.
# See motion.md §11 (Out of scope).

# ── Native / build prerequisites (per platform) ───────────────
# Android:
#   - JDK 17
#   - Android Studio (SDK Platform 34+)
#   - The dev build is created by `npx expo run:android`, which
#     generates `android/` on first run and uses
#     `google-services.json` (already in the repo, do not commit
#     a different one).
# iOS:
#   - Xcode 15+ and CocoaPods (`sudo gem install cocoapods`)
#   - `npx expo run:ios` generates `ios/` and runs `pod install`.
# Web:
#   - Just `npx expo start --web`. No native modules run on web.

# ── Admin seed script (separate setup, see adminsetup.md) ─────
# In addition to the npm packages above, granting a new admin
# account requires:
#   1. A Firebase service-account key (JSON), downloaded from
#      Firebase Console → Project Settings → Service accounts.
#   2. The env var `GOOGLE_APPLICATION_CREDENTIALS` pointing at
#      that JSON file. See `Documentation/04-Firebase/adminsetup.md`
#      for the full step-by-step.
#   3. The `firebase-admin` package (already in dependencies).

# ── Security notes ─────────────────────────────────────────────
# - Never commit the service-account JSON file. The .gitignore in
#   the repo root SHOULD exclude `*-firebase-adminsdk-*.json` and
#   `service-account-*.json`; if you find it missing those entries,
#   add them.
# - Never commit your `.env` file. It contains anon keys which are
#   still client-visible and shouldn't be in the public repo.
# - The Clerk / Twilio / Stripe / paid-Map-providers packages
#   are NOT and will never be in this file. EdumentX is a
#   zero-budget demo.
