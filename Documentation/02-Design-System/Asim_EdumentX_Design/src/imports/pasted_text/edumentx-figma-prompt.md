## 📋 Copy-Paste Figma Prompt (paste directly into Figma AI or share with your designer)

---

> **Design a complete mobile app UI for EdumentX — a location-based home tutor discovery platform for Kathmandu Valley, Nepal. The app is built in React Native (Expo) for Android and iOS. Design all screens at 390×844px (iPhone 14 base frame), 1× scale, with auto layout components.**
>
> **Brand identity:** Primary color is Deep Education Blue (#185FA5 active, #E6F1FB light fill). Accent is Teal (#1D9E75) for the Blue Tick verification badge and enrollment success states. Use Amber for warnings/pending states, Coral/Red for rejection/errors, Purple (#534AB7) exclusively for AI chatbot elements. Neutral backgrounds: #F5F5F3 page background, white (#FFFFFF) card surfaces. All borders are 0.5px solid at 15% opacity. No gradients, no drop shadows, no glow effects. Flat, clean, trustworthy aesthetic.
>
> **Typography:** Use Inter or SF Pro. Scale: 22px/500 for screen titles, 18px/500 for section headers, 16px/500 for card titles, 14px/400 for body text, 12px/400 for captions, 11px/500 uppercase for overline labels. Two weights only: 400 and 500. Sentence case everywhere.
>
> **Spacing system:** 16px horizontal page margin, 12px gutter between cards. Card padding: 16px horizontal × 14px vertical. All interactive elements minimum 44×44px. Border radius: 8px chips/badges, 12px cards, 16px modals and bottom sheets, 999px for pills and avatars.
>
> **Design these 24 screens across 3 user roles:**
>
> ONBOARDING: (1) Splash screen with centered logo and brand blue background. (2) 3-slide onboarding carousel with illustrations showing map discovery, AI chatbot, and tutor verification — each slide has headline, subtext, dot indicator, and Next/Skip button. (3) Role selection screen with two large tappable cards: Student/Parent (student icon) vs Tutor (teacher icon). (4) Phone number entry with Nepal country code +977, phone input field, and primary Send OTP button. (5) OTP verification with 6-box input row, 60-second countdown timer, and Resend link. (6) Profile setup form with photo upload avatar circle, name/email fields, grade and subject selection, and a location detection bar with auto-detect button and manual map pin fallback.
>
> STUDENT/PARENT FLOW: (7) Home feed with greeting header showing user name, current location bar, prominent search input, horizontal scroll row of Nearby Tutor cards, and a Verified Tutors section below. (8) Map search screen — full-screen Google Map with tutor location pins (blue circles for unverified, teal circles for Blue Tick verified tutors), semi-transparent service area radius overlays, a floating top search bar, a floating radius slider pill showing "Showing tutors within X km", and a bottom sheet with a list/map toggle and scrollable tutor cards sorted by distance. (9) Filter bottom sheet modal with subject multi-select chips, distance range slider (1–20 km), monthly rate range slider, verification status toggle, minimum star rating selector, and sort options (distance / rating / price / experience). (10) Tutor profile screen with 180px hero image showing neighborhood map overlay, 64px avatar circle, tutor name with inline 16px teal Blue Tick badge, a 3-column stats row (star rating, years experience, monthly rate in Rs), subject chips, collapsible About section, Reviews section with star rating histogram, demo video thumbnail, and a sticky bottom CTA bar "Enroll with [name]". (11) Enrollment form with 4-option plan duration selector pills (1 / 3 / 6 / 12 months), start date calendar picker, days-per-week chip selector (Mon–Sun), teaching address input, map pin for location confirmation, optional trial week toggle, and Submit button. (12) AI Chatbot screen with purple (#3C3489) header bar showing "EdumentX AI" label and online indicator, chat history with right-aligned user bubbles (blue-50 fill) and left-aligned AI response bubbles (white card), embedded tutor recommendation mini-cards inside AI bubbles showing avatar/name/rating/distance/rate, a text input bar with send button, and 3–4 quick-suggestion chips above the keyboard ("Find Maths tutor", "Under Rs 3,000", "Near Lalitpur"). (13) My Enrollments screen with Active / Pending / Past tab bar, each item showing tutor photo, name, subject chips, enrollment dates, status badge, and a View Details arrow. (14) Rate & Review screen with 5-star tap row, written review textarea with character count, and Submit button — locked with explanatory message until enrollment period ends.
>
> TUTOR FLOW: (15) Tutor dashboard with 4 metric cards (total active students, average rating, pending requests, total months taught), a Requests section showing student name/grade/subject/plan, and an availability toggle switch. (16) Edit profile screen with photo upload, subjects multi-select, monthly rate input, qualifications text area, years experience stepper, service radius map with adjustable circle overlay, and availability weekly calendar grid. (17) Document upload screen with three dashed-border upload zones (Citizenship ID, Academic Certificates, Demo Video with 60s limit label), upload progress bar, thumbnail previews after upload, and a full-width Amber "Verification pending — admin will review within 48 hours" banner. (18) Enrollment inbox with pending request cards showing student photo, name, grade, plan duration, proposed schedule, start date, and three action buttons: Accept (green), Reject (red outlined), Counter-offer (blue outlined). (19) Group batch creation screen with subject selector, batch name, max seats number input, monthly rate, weekly schedule chip grid, description field, and a current roster list with seat capacity fill bar. (20) Capacity manager with a visual seat grid (teal filled = occupied, outlined = available), current student names list, and a max capacity stepper.
>
> ADMIN PANEL: (21) Admin login with email/password form, no OTP, security lock icon header. (22) Verification queue list with tutor name, submission date, document thumbnail previews, and Approve / Reject / Request More Info action buttons — approved rows show Blue Tick badge. (23) User management table with search bar, role filter tabs (All / Student / Tutor), user rows showing avatar/name/role/join date/status badge, and row-level Suspend / Reinstate / Remove actions. (24) Platform statistics screen with 4 KPI metric cards (total registered users, active enrollments, verified tutors percentage, average platform rating), a weekly enrollment trend line chart, and a subject demand horizontal bar chart.
>
> **Additional requirements:** Design all empty states (no search results, location permission off, no enrollments yet, verification pending). Design error states (network offline banner, tutor at full capacity warning). Create a reusable component library including: tutor card (compact and full), Blue Tick badge, status badge set, enrollment plan pill selector, star rating row, subject chips, bottom navigation bars for both roles, map pin variants, and chat bubble pair. Set up auto layout on all components. Use Figma Variables for the color system and type styles. Prepare a prototype connecting all screens with realistic transitions: push for navigation, slide-up for bottom sheets, fade for modals.
