## 2. Skills

Skills are prompt packs that the `Skill` tool loads on demand. They
fall into three groups based on where they live.

### 2.1 Universal skills (`~/.agents/skills/`)

Installed by the standalone `skills` CLI. Available across every
project on this machine.

| Name | Source | Invocation | Purpose |
|---|---|---|---|
| `find-skills` | anthropics/skills | auto | Discover / install skills from the open ecosystem |
| `grill-me` | anthropics/skills | `/grill-me` only (`disable-model-invocation: true`) | Relentless interview to sharpen a plan |

## 4. MCP Servers

Model Context Protocol servers expose tools (like `mcp__stitch__*`)
that the model can call directly. Configured globally in
`~/.claude.json` under `mcpServers`.

| Name | Type | URL | Auth | Active |
|---|---|---|---|---|
| `stitch` | http | `https://stitch.googleapis.com/mcp` | `X-Goog-Api-Key` header in `~/.claude.json` | **Yes** |

**Tools exposed by `stitch`** (auto-prefixed `mcp__stitch__`):

- `list_projects` · `get_project` · `delete_project` · `create_project`
- `list_screens` · `get_screen` · `generate_screen_from_text`
- `edit_screens` · `generate_variants`
- `list_design_systems` · `create_design_system`
- `update_design_system` · `apply_design_system`
- `upload_design_md` · `create_design_system_from_design_md`

Use `stitch` whenever the user wants a Figma-style design scaffold.
Pair with the `frontend-design` plugin skill for prompting tips.

**Project-local MCP**: none. `.mcp.json` does not exist; the project's
entry in `~/.claude.json` has empty `mcpServers`, `enabledMcpjsonServers`,
and `disabledMcpjsonServers` arrays.

## 6. The recommended workflow for EdumentX tasks

When starting a new non-trivial task, run through this checklist:

1. **Brainstorm** with `superpowers:brainstorming` — clarify scope,
   constraints, anti-patterns.
2. **Write a plan** with `superpowers:writing-plans` — produce a
   step-by-step plan with verification gates.
3. **Set up a worktree** with `superpowers:using-git-worktrees` if
   the task spans more than one commit.
4. **Dispatch** via `superpowers:dispatching-parallel-agents` or
   `superpowers:subagent-driven-development` if scope is broad.
5. **Code TDD-first** with `superpowers:test-driven-development` —
   `react-native-best-practices` for perf-sensitive work.
6. **Debug systematically** with `superpowers:systematic-debugging`
   if anything goes wrong.
7. **Self-review** with `superpowers:requesting-code-review` →
   `/code-review medium`.
8. **Verify** with `superpowers:verification-before-completion` and
   `/verify` (drives the app end-to-end).
9. **Finish the branch** with
   `superpowers:finishing-a-development-branch`.

**Forbidden** (matches `CLAUDE.md`):

- Reintroducing Tamagui.
- Hardcoding hex colors outside `constants/colors.ts`.
- Adding paid deps (Cloud Storage / Functions / Google Maps SDK /
  OpenAI / Anthropic / Cohere / Mapbox / Algolia).

## 7. Anti-patterns for this tool stack

- **Don't paste a stale skill list into a prompt** — this doc is the
  source of truth. Regenerate it (see below) if anything is missing.
- **Don't invoke a skill by name in user-facing copy** unless the
  user explicitly asked. The `Skill` tool is auto-invoked when the
  description matches.
- **Don't disable `superpowers:verification-before-completion`** —
  it's the last line of defense against shipping a broken change.
- **Don't load every skill at session start** — skills are loaded
  on-demand. Trust the description matcher.
- **Don't add new MCP servers without updating this doc** — the
  `stitch` server is the only one authorized for EdumentX (design
  generation only). Anything else (CI, DB, payment) needs an
  explicit decision in `01-Architecture/ARCHITECTURE.md` first.

## 8. How to regenerate this document

If the user asks "is X still installed?" or "what's new in the tool
stack?", run these commands and update the doc:

```bash
# Skills
ls ~/.agents/skills/                # universal
ls .claude/skills/                  # project-local
ls ~/.claude/plugins/cache/*/*/skills/  # plugin-bundled

# Plugins
cat ~/.claude/plugins/installed_plugins.json
cat ~/.claude/plugins/known_marketplaces.json

# MCP servers
grep -A 20 '"mcpServers": {' ~/.claude.json
cat .mcp.json 2>/dev/null          # project-local
```

Regenerate the markdown tables from those outputs. Pin a date in the
"Last verified" header.
