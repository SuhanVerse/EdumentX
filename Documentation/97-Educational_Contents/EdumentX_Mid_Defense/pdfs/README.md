# pdfs

Reserved for compiled PDFs and external source PDFs that you
want to `\includegraphics` or link to from `main.tex` (for
example, the signed approval page or a one-page architecture
overview rendered as a PDF page).

## Suggested contents

- `approval-page.pdf` — the signed approval page (replace the
  placeholder in `main.tex` with `\includegraphics{pdfs/approval-page.pdf}`).
- `design-palette.pdf` — a one-page cheat sheet of the
  ``Night & Sand'' design tokens.
- `firestore-rules.pdf` — export of the deployed
  `firestore.rules` file, for the Appendix chapter once added.

This folder is intentionally empty at the mid-term milestone.
The team will drop files in as they are produced.
