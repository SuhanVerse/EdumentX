# Figma Make Prompts

This folder stores cleaned prompt material for regenerating or improving the EdumentX app design in Figma Make.

Use these files:

- `FINAL_FIGMA_MAKE_PROMPT.md` - final ready-to-copy prompt for Figma Make.
- `DESIGN_PROMPT_ISSUES_AND_FIXES.md` - problems found in the attached prompts/design context and how the final prompt fixes them.

Best files to attach in Figma Make or another AI model:

- `Documentation/design-context/EdumentX-Design-Extraction.md`
- `constants/theme.ts`
- `Prompts/FigmaMake/FINAL_FIGMA_MAKE_PROMPT.md`
- Current screen screenshots if you want the generated design to match the existing implementation.

Do not attach `.env`, API keys, Firebase secrets, `node_modules`, `.expo`, `dist`, `android`, or `ios`.
