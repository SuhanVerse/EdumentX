# BasoBas — Complete Feature List
## Every Feature, Who It Serves, and Whether It Is Free or Pro

---

## Core Features — Free for All Users

These features are available to every user regardless of plan.
They form the foundation of the product and cannot be
gated or restricted.

```
01  Phone Number OTP Authentication
    All users authenticate via Nepal phone number + SMS OTP.
    No email, no social login, no password.

02  Dual Role System
    One account holds both Tenant and Landlord roles.
    Switch instantly from Profile screen.

03  Structured Rental Listing Management
    Landlords create listings with type, photos, rent,
    facilities, rooms, and two-tier location privacy.

04  Property Discovery — Browse
    Tenants browse listings on home feed in sections:
    Nearby, Trending, Recommended.

05  Property Discovery — Search
    Full-text search with filters: type, price range,
    bedrooms, facilities, verified landlords only.
    Sort by: relevance, price, newest, rating.

06  Property Discovery — Map
    Full-screen map with price pins, clustering,
    bottom sheet list view, and type filter chips.

07  Property Status System
    Four real-time public statuses on every listing:
    Available · High Demand · Under Discussion · Occupied

08  Visit Request Workflow
    Tenant submits request with date + time + message.
    Landlord accepts, reschedules, or rejects.
    Full lifecycle from PENDING to RENTAL_FINALIZED.
    Location unlocked on ACCEPTED status only.

09  Post-Visit Follow-Up System
    System prompts both parties 2 hours after visit time.
    Tenant: 4 response options.
    Landlord: 4 response options.
    Automated reminders if no response within 48 hours.

10  Real-Time Notification System
    13 notification types covering the full visit lifecycle.
    Grouped by date, color-coded, deep-linked to screens.

11  Basic AI Rental Suggestions
    Behavioural recommendations based on browsing history.
    Generic feed for new users based on selected city.

12  Ratings & Reviews — Tenant Reviews Landlord
    After visit completion, tenant can rate and review.
    1–5 stars + optional text (max 300 characters).
    Public, visible to all users.

13  Ratings & Reviews — Landlord Rates Tenant
    Star rating only (no text) after visit completion.
    Private — visible only to future landlords when
    reviewing visit requests from this tenant.

14  Landlord Identity Verification (KYC)
    Citizenship or National ID card verification.
    Mandatory before landlord can publish any listing.
    Displays Verified badge on profile and all listings.

15  Profile Management
    Name, photo, city, property type preferences.
    Mandatory for all users (name + city required).

16  Saved Properties
    Tenants can save/unsave any listing.
    Accessible from Profile → Saved Properties.
    Notifications when saved property changes status.

17  Multiple Applicants Management
    Multiple tenants can request visits to one property.
    Each request managed independently by landlord.
    All auto-close when one is finalized.

18  Listing Draft System
    Landlords can save incomplete listings as drafts.
    Drafts not visible publicly until published.
    Unverified landlords can draft but not publish.
```

## Free Tier Limits

These limits exist on the free plan to create a
natural upgrade moment for serious tenants.

```
Active visit requests:   Maximum 3 simultaneously
AI recommendations:      Basic behavioural only, no preferences
Early listing access:    Public feed only (no 24h head start)
Request queue position:  Standard (not prioritized)
Profile badge:           None (no Pro badge)
```

---

## Pro Features — Tenant Only, Paid Plan

These 5 features are locked behind the Pro plan.
Exactly 5 features — no more, no less for MVP.

```
P1  Early Listing Access — 24-Hour Head Start
    New listings shown to Pro tenants exclusively for 24 hours
    before appearing in the public feed.
    Free users see blurred locked cards with countdown timer.

P2  AI Suggestions via Preferences Setup
    Pro tenants unlock full preferences configuration in Profile.
    Set preferred types, budget, areas, facilities explicitly.
    AI uses these as highest-weight signals immediately.
    Home feed becomes highly personalized from first session.

P3  Priority Visit Requests
    Pro tenant's request appears at the TOP of the landlord's
    incoming request list with "⭐ Pro Verified Tenant" badge.
    Landlord still decides freely — this is a trust signal.

P4  Unlimited Visit Requests
    Removes the 3-request cap entirely.
    Pro tenants can have unlimited simultaneous active requests.

P5  Pro Verified Badge
    Gold "⭐ PRO" badge on profile and all visit requests.
    Signals to landlords: serious, paying, urgent tenant.
    Three size variants: inline, profile, and lock badge.
```

## Features That Will Never Be Gated

These must always remain free. Gating any of these
would break the core product experience.

```
Browse all listings                 → Discovery depends on this
View property details and photos    → Core product experience
At least 3 visit requests           → Core workflow
All visit status notifications      → Safety and communication
Basic OTP auth and profile          → Identity foundation
KYC verification                    → Trust and safety
Writing reviews after visits        → Platform integrity
Notification on/off controls        → Legal requirement
Saving properties                   → Engagement feature
Basic search and filter             → Discovery foundation
```
